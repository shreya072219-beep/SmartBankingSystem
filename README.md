## Application Workflow

1. User creates a new account.
2. System generates an account number.
3. User logs in using account number and PIN.
4. User can perform banking operations:
   - View account details
   - Deposit money
   - Withdraw money
   - Transfer money
   - View transaction history
   - Add interest
5. User logs out from the system.

## Functional Modules

### 1. Account Module
Handles:
- Account creation
- User authentication
- Account details management

### 2. Transaction Module
Handles:
- Deposits
- Withdrawals
- Transfers
- Transaction records

### 3. Interest Module
Handles:
- Interest calculation
- Balance updates
